# kdb+ Crypto Tickerplant & Analytics Engine

A simulated real-time market data system built with kdb+/q, modeled on the three-tier tick architecture used in production at financial institutions.

## Architecture

```
[Python Feed] --> [Tickerplant (TP)] --> [Real-Time DB (RDB)] --> [Historical DB (HDB)]
                                                |
                                         [Analytics / Dashboard]
```

- **Tickerplant** — receives raw price feed, timestamps each tick, publishes to subscribers
- **RDB** — in-memory database holding today's tick data, subscribes to TP
- **HDB** — on-disk historical database, end-of-day write from RDB
- **Feed** — Python script simulating live crypto prices (BTC, ETH, SOL, BNB)
- **Dashboard** — Python Dash app querying the RDB for live analytics

## Tech Stack

- kdb+/q (free personal edition)
- Python 3.x (websockets, requests, dash, pandas)
- Linux/Unix process management

## Quick Start

### Prerequisites

1. Download kdb+ personal edition free from [kx.com](https://kx.com/developers/)
2. Install Python dependencies:
```bash
pip install dash pandas requests websocket-client
```

### Run the stack (4 terminal windows)

**Terminal 1 — start the Tickerplant**
```bash
q q/tick.q sym . -p 5010
```

**Terminal 2 — start the RDB**
```bash
q q/rdb.q -p 5011
```

**Terminal 3 — start the price feed**
```bash
python python/feed.py
```

**Terminal 4 — start the dashboard**
```bash
python python/dashboard.py
# open http://localhost:8050
```

## q Queries (run in any q session connected to RDB)

```q
/ connect to RDB
h: hopen 5011

/ last price per symbol
h "select last price by sym from trade"

/ VWAP by symbol
h "select vwap: wavg[size; price] by sym from trade"

/ 5-tick moving average for BTC
h "select sym, price, mavg5: 5 mavg price from trade where sym=`BTCUSD"

/ volatility (std dev) per symbol
h "select vol: dev price by sym from trade"

/ trade count and total volume
h "select count i, sum size by sym from trade"

/ asof join trades to quotes
h "aj[`sym`time; trade; quote]"
```

## Key Concepts Demonstrated

| Concept | Implementation |
|---|---|
| Tick architecture | TP → RDB → HDB three-tier pattern |
| Columnar storage | Typed kdb+ tables with `flip` schema |
| IPC | `hopen`/`hclose` inter-process communication |
| upd[] pattern | Standard tickerplant insert function |
| Time-series joins | `aj[]` asof join on sym+time |
| Vector operations | `mavg`, `wavg`, `dev` on price columns |
| EOD write | RDB flush to HDB at end of day |
